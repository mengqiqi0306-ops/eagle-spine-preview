# spine动画预览

## 简介

在 Eagle 中按空格播放 Spine 动画，后台自动生成动态缩略图。支持多版本 JSON、二进制及常见 Unity 导出后缀，仅限 Windows。

## 插件描述

直接在 Eagle 中查看 Spine 动画，无需反复切换查看器。选中骨骼文件或图集，按空格即可打开预览；导入完整配套素材后，后台会自动生成动态缩略图，无需先打开文件。

**主要功能**

- 空格预览：选中素材即可播放，也可从插件菜单打开。
- 动画控制：切换动作和皮肤，播放或暂停，调整速度、循环和时间轴。
- 查看细节：滚轮缩放、拖动平移、一键适应窗口。
- 自动动态缩略图：后台检查素材并生成循环缩略图；后台保留已有自定义缩略图。
- 手动生成：按当前选择的动作生成动态缩略图；手动操作会更新已有缩略图。

**支持范围**

- Spine 3.6、3.7、3.8、4.0、4.1、4.2、4.3。4.3 为当前已测试的 beta 版本，不保证其他 beta 更新或未来版本兼容。
- 二进制骨骼：`.skel`、`.skel.bytes`、包含 Spine 骨骼数据的 `.bytes`。
- JSON 骨骼：`.json`、`.json.txt`、`.json.bytes`、包含 Spine JSON 数据的 `.txt`。
- 配套图集：`.atlas`、`.atlas.txt`、`.atlas.bytes`。
- ZIP / `.spinezip` 素材包。后台自动识别素材包时建议使用 `.spinezip` 后缀；普通 `.zip` 可打开预览。

需要导出的骨骼、图集和纹理配套使用，不支持直接播放 Spine 编辑器的 `.spine` 工程。普通 JSON、TXT、BYTES 或 ZIP 不等于 Spine 动画。

**安装与使用**

1. 安装插件后，完全退出并重新启动 Eagle。
2. 把骨骼、图集和图集引用的纹理一起导入，建议放在同一个 Eagle 文件夹。
3. 选中骨骼或图集，按空格播放。后台也会自动检查素材，不需要首次打开才能生成缩略图。

**环境与后台行为**

仅支持 Windows。本机已验证 Eagle 4.0.0 build 20260401，需要 Eagle 本地 API 可用并提供 `/api/v2/` 接口；更早版本兼容性尚未验证。

后台约每5秒检查当前素材库中的相关文件，更新缩略图及尺寸元数据，不覆盖原始骨骼、图集或纹理。缩略图最长3秒、20fps、最大边256像素。配套文件不完整时会等待并重试，重复同名素材可能需要整理。

停用插件可停止后台工作；已生成的缩略图会保留。列表中的动态缩略图播放表现还取决于 Eagle 的缩略图播放设置。

**隐私与第三方依赖**

素材在本机处理，通过 `127.0.0.1:41595` 与 Eagle 本地 API 通信，不上传到外部服务。缩略图生成使用系统临时文件，完成后清理；插件记录后台运行状态。使用 Esoteric Software 的 Spine Runtimes，对应许可证和版权声明随插件提供。本插件为独立开发作品。
