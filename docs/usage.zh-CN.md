# spine动画预览：使用说明

## 安装

安装社区提供的 `.eagleplugin` 文件后，完全退出 Eagle 再重新启动。插件同时提供空格预览和后台缩略图生成，只需安装一个插件。

当前仅支持 Windows。本机验证环境为 Eagle 4.0.0 build 20260401；需要可用的 Eagle 本地 API 及 `/api/v2/` 接口。

## 导入素材

把完整配套文件一起导入 Eagle，建议放入同一个 Eagle 文件夹，例如：

```text
robot-demo.json       骨骼数据，也可以是 .skel
robot-demo.atlas      图集
robot-demo.png        图集引用的纹理
```

不要修改图集所引用的纹理名称。多张纹理也需要全部导入。存在重复同名素材时，尽量将不同角色分开放置，避免匹配到错误的配套文件。

也可以使用 ZIP 素材包。若希望后台自动识别包并生成缩略图，建议将 ZIP 的扩展名改为 `.spinezip`，它仍然是普通 ZIP 容器。

## 播放动画

1. 在 Eagle 中选中骨骼文件或图集。
2. 按空格打开预览，动画会自动播放。
3. 在顶部选择动作、皮肤和速度；点击“暂停”可停止播放。

| 操作 | 用途 |
| --- | --- |
| 动作 | 切换导出文件中已有的动画 |
| 皮肤 | 切换导出文件中已有的皮肤 |
| 速度 | 调整播放速度 |
| 循环 | 设置是否循环播放 |
| 时间轴 | 拖动到指定时间，拖动后暂停 |
| 滚轮 | 放大或缩小 |
| 鼠标拖动 | 平移画面 |
| 适应窗口 | 恢复适合窗口的缩放与位置 |
| PMA | 纹理边缘显示异常时，核对导出的预乘透明设置 |
| 读取当前选中 | 从 Eagle 重新读取当前选中的素材 |
| 打开素材 / 选择配套文件夹 | 手动提供骨骼、图集和纹理 |

皮肤或动作下拉列表只有一个选项时，通常表示导出素材本身只有一个皮肤或动作。

## 自动动态缩略图

导入完整配套素材后，不用先按空格打开，后台会自动检查并生成动态缩略图。后台约每5秒检查一次；生成时间还取决于素材数量、资源大小和电脑性能，不保证5秒内完成。

- 默认动作生成最长3秒的循环缩略图，20fps，最大边256像素。
- 后台保留已有自定义缩略图。
- 需要换成其他动作时，打开预览、选好动作，再点击“生成动态缩略图”。此手动操作会更新已有缩略图。
- 动态缩略图在 Eagle 列表中的播放表现还取决于 Eagle 的缩略图播放设置。
- 插件会更新缩略图和尺寸元数据，不覆盖原始骨骼、图集及纹理。
- 停用插件会停止后台检查，已经生成的缩略图仍会保留。

## 支持格式与版本

| 数据类型 | 支持的常见后缀 |
| --- | --- |
| 二进制骨骼 | `.skel`、`.skel.bytes`、`.bytes` |
| JSON骨骼 | `.json`、`.json.txt`、`.json.bytes`、`.txt` |
| 图集 | `.atlas`、`.atlas.txt`、`.atlas.bytes` |
| 完整素材包 | `.zip`、`.spinezip`；后台识别包建议使用 `.spinezip` |
| 纹理 | 图集引用的 PNG、JPG/JPEG、WebP |

文件内容必须是对应的 Spine 导出数据。仅修改扩展名不能把普通文件变成 Spine 素材。

当前支持 Spine 3.6、3.7、3.8、4.0、4.1、4.2、4.3；4.3 按当前已测试的 beta 版本支持，不保证其他 beta 更新或未来版本兼容。编辑器 `.spine` 工程需要先导出骨骼数据、图集和纹理。

## 常见问题

**一直等待素材，或提示缺少配套文件**

检查骨骼、图集及全部纹理是否导入齐全，图集中的纹理名称是否匹配；把同一套文件放入同一 Eagle 文件夹。新增配套文件后，后台会重试；前台可重新按空格或点击“读取当前选中”。

**可以播放，但没有自动缩略图**

先确认安装后已完全退出并重启 Eagle，然后检查是否已有自定义缩略图。普通 ZIP 建议使用 `.spinezip` 后缀。若后台显示本地 API 错误，检查 Eagle 是否提供所需接口；也可以打开预览后手动生成。

**画面透明边缘发黑或有色边**

核对素材导出的 PMA 设置，尝试切换预览中的 PMA 选项。缺失纹理或版本不匹配则需要重新提供正确素材。

**提示版本不支持**

检查实际导出版本是否在上述范围内；不建议仅修改 JSON 中的版本号。

## 原创示例

“原创机器人示例.zip”内包含可用于演示和分发的机器人素材。解压后，将 JSON、atlas 和 PNG 一起导入 Eagle；选中 JSON 按空格可播放 `wave` 动作。

## 数据处理

预览和缩略图生成在本机完成。插件通过 `127.0.0.1:41595` 与 Eagle 本地 API 通信，不把素材上传到外部服务。生成过程中使用系统临时文件，完成后清理；后台运行状态用于显示和排查错误。
